# Sales Forecasting Model

## Project Overview
This project focuses on forecasting daily sales using a time-based regression model. The goal is to identify sales trends and predict future performance.

## Dataset
Simulated daily sales data including:
- Date
- Sales value
- Time index (day number)

## Objectives
- Analyze sales trend over time
- Build a linear regression model
- Evaluate model performance using MAE
- Predict future sales

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Model Evaluation
The model was evaluated using Mean Absolute Error (MAE).

## Business Impact
Sales forecasting helps businesses:
- Plan inventory
- Optimize budgeting
- Improve strategic decision-making
